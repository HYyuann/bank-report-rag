# tools/ —— 第五步评测的排查脚本

这些不是流水线的一部分（流水线只到 `app.py` / `ask.py` / `rag.py`），
是写 `eval_report.md` 时逐条核对用的现场脚本，**留在这里是为了报告里每一句
归因都能被复核**。都在仓库根目录下运行，例如：

```bash
.venv/Scripts/python.exe tools/chk3.py
```

（脚本里用的是相对路径 `chunks.jsonl` / `eval_raw.json`，所以必须从根目录跑。）

## 原始结果 -> 总表

| 脚本 | 作用 |
|---|---|
| `table.py` | 读 `eval_raw.json`，输出 `eval_report.md` 里那张 10 行总表。判定列是人工核对后写死的常量 `VERDICT`，客观量（命中数/首条/GT）从 json 取 |
| `view.py` | 打印指定题在三种配置下的命中列表 + 完整答案 |
| `view2.py` | 同上，题目是 Q2/Q4/Q5/Q7/Q10，答案截断到 430 字 |

## Ground truth 核对（直接从 chunks.jsonl 核，不查外部资料）

| 脚本 | 作用 |
|---|---|
| `truth.py` | 核 Q1–Q3 的 GT 数值（692.35 / 1.29 / 1.83）及其干扰项 |
| `truth2.py` | 核 Q4–Q7 的 GT 数值与所在块 |
| `truth3.py` | 核 Q9 的 12 家拨备覆盖率两期数值 |
