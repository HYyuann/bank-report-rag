三个案例

案例一 · Q6 交通银行拨备覆盖率｜三路全拒，根因在第二步的表格重建。 值 203.80% 在 p10-10 块，三路都没有召回它；被召回的 p10-12 块里连「拨备覆盖率」五个字都没有。 看 p10-10 那一行的形态就知道为什么： 拨备覆盖率 | | | | | | | | | | | 203.80 —— 指标名与值之间隔着 11 个空单元格， 是第二步坐标法重建表格时展开合并单元格的产物。后果有两层：BM25 侧该块大半 token 就是「|」， 词邻近性信号被稀释光；向量侧编码器看到的是一串孤立数字而非一张拨备覆盖率表。 模型的拒答理由（「6 段材料均无该指标」）完全属实 —— 这是漏检，不是幻觉。 对照：同一题混合+过滤召回 6/6 交行且首条正确，说明公司过滤这一层工作正常， 出问题的是进入融合之前的语料形态；而向量/BM25 的首条分别是浦发银行 p54-55 的同名指标表， 正是公司过滤要治的那类错。

案例二 · Q10 边界题｜抗幻觉约束把一道「其实有答案」的题也拒了，且出题时 GT 标错。 出题假设「语料只有 2026H1」，于是把 GT 设为空、把拒答当正确。实测语料里有： 招行公司治理 p72「按照经审计的本公司 2025 年度净利润 1,361.84 亿元的 10% 提取法定盈余公积 136.18 亿元」。 更关键的是 BM25 恰好把该块排到首条，模型看了它，仍然拒答，理由是「该数字用于说明利润分配方案， 未明确为全年净利润口径」。这是个双面案例：好的一面是抗幻觉很稳 —— 它没有把 2026H1 的集团数 769.19 亿 当成 2025 全年度数，也没有编数；代价是严格拒答吃掉了召回率。而真正该记的是标注错误： 「语料时段外的问题」和「语料里没有的数」不是一回事 —— 半年报必然含上年分配基数这类跨期数字。 口径风险也真实存在：1,361.84 亿是本公司口径，与集团口径不可比。

案例三 · Q7 一句话三子问题｜三路差距最大的一题（0/3 → 2/3 → 3/3）。 只用 BM25 召回的 6 块是招商/民生/中信/平安/中行，一块农业银行都没有，它没有乱答 （输出了他行真实数据并声明「材料中没有农业银行」），但完全没用；只用向量 6/6 全是农行， 却只答出净利息收入 3,122.44 亿和不良率 1.25%，第 3 项拨备覆盖率所在页没进 top-6； 混合+公司过滤三项全对（3,122.44 / 1.25 / 290.10），并主动排掉两个陷阱： 「不良贷款率 1.05%、拨备覆盖率 350.76% 是县域金融分部口径，不是全行」、 「贷款拨备率 3.63 ≠ 拨备覆盖率」。多子问题不是靠更强的模型解决的，是靠检索把三页都召回。

关键结论

  1. 修好「串公司」的是公司过滤，不是 RRF。单公司题 top-6 命中均值：混合+过滤 6.00， 无过滤量级 3/6~4/6；RRF 单独上甚至比只用向量更差（Q1 首条落到平安银行 p47）。 RRF 只看名次，会抬高「两路都中等」的块，压过「单路最好」的块。
  2. 「找对公司」已解决（首条正确率 7/7），「找对页」仍靠运气。 17 次拒答里有 5 次（Q5、Q6）是混合已经拿到 6/6 目标公司块却仍答不出 —— 因为承载数值的那一页没被召回。要提分该动块粒度，不是继续调 RRF 的 K 或换更大的向量模型。
  3. 表格重建的副产品会同时废掉 BM25 和向量。指标名与值隔 11 个空单元格（Q6）、 标签块与数字块分离（建行 p8-10 只有标签、p7-8 只有 30 多个数字零标签）， 两种形态同时打击词邻近性与语义编码，而症状表现为「模型拒答」，很容易误判成模型能力问题。
  4. 跨公司全景题（Q8/Q9）单次检索结构上无法回答。top-6 覆盖不了 12 家 × 两期； Q9 还更深一层 —— 建行/兴业的 2025 年末值在语料里已被表格切分丢失，多轮检索也补不齐， 必须先修数据再接多轮。
一句话结论（可直接填入提交文本框）

指名公司、指标明确的单点题适合建库检索（混合 + 公司过滤可稳定命中）；跨公司比较、跨期对比、表格密集的数值题不适合单次检索，需要多轮检索 / 图谱或微调。
